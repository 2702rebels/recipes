## Before you start

Every procedure assumes the [general tuning workflow](/docs/controls/ctre/foundation#15-general-tuning-workflow): set mechanism units first, choose `StaticFeedforwardSign` for the request you'll use, and get the feedforwards right before adding kP. If you're not sure which output family to use, see [Choosing a Control Mode](/docs/controls/ctre/selection).

## Printing procedures for the practice field

Each procedure panel has a **Print** button that prints just that procedure. On the Voltage Control and Torque-Current Control pages, **Print all procedures on this page** prints every procedure there, one per sheet. Turn on background graphics in the print dialog to keep the panel colors and step numbers.
